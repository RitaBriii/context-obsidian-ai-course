# Начните здесь

Добро пожаловать в курс по накопительному контексту, Obsidian и работе с ИИ-ассистентами.

Этот проект нужно проходить в Codex. Все задания выполняются в файлах репозитория, а Codex ведет вас по ним как наставник.

Если вы автор курса или администратор платформы и тестируете прохождение, сначала сделайте отдельную копию проекта. Не проходите курс в исходной папке, которую будете публиковать.

## Подготовка

1. Откройте папку проекта в Codex.
2. Найдите файл `AGENTS.md`. Codex использует его как инструкцию наставника.
3. Найдите файл `course/README.md`.
4. Найдите файл `student-work/progress.md`.
5. Откройте шпаргалку `handouts/markdown-basics.md`.
6. Начните новую задачу Codex в этой папке.

Obsidian понадобится во втором модуле. Если он еще не установлен, ассистент мягко проведет вас через установку и открытие vault.

## Стартовый промпт

Скопируйте текст ниже в ассистента:

```text
Привет! Я прохожу курс из этого репозитория: "От хаоса к системе: Obsidian для личного контекста".

Пожалуйста, будь моим наставником по курсу. Веди меня последовательно в этой задаче и считай файлы источником истины о моем прогрессе.

Учитывай файлы:
- AGENTS.md
- course/README.md
- handouts/markdown-basics.md
- student-work/progress.md

Я только начинаю вайбкодить, поэтому объясняй простыми словами, но не упрощай смысл. Мне важно понять теорию накопительного контекста, научиться вести Obsidian vault и выполнять задания в файлах проекта.

Когда просишь меня открыть или заполнить файл, давай кликабельную Markdown-ссылку на реальный файл. Если можешь прочитать файл сам, не проси меня копировать его содержимое: скажи, какие поля заполнить, а после моего сообщения «готово» проверь файл сам.

Не заполняй за меня упражнения, где нужны мои цели, опыт, наблюдения или решения. Сначала объясни задание и задай один вопрос.

Начни с вводного урока и скажи, какой файл открыть первым.
```

## Правила прохождения

- По возможности не создавайте новую задачу для каждого урока.
- Не пропускайте чекпоинты.
- Не храните важные выводы только в диалоге.
- После каждого модуля обновляйте `student-work/progress.md`.

## Если ассистент сбился

Скопируйте ему этот текст:

```text
Вернись к роли наставника из AGENTS.md. Сначала сам прочитай student-work/progress.md, затем продолжи с ближайшего незавершенного модуля.
```
