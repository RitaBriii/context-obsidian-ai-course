# Начните здесь

Добро пожаловать в курс по накопительному контексту, Obsidian и работе с ИИ-ассистентами.

Этот проект нужно проходить в VS Code вместе с ассистентом. Все задания выполняются в файлах этого репозитория, а весь курс ведется в одном диалоговом окне.

Если вы автор курса или администратор платформы и тестируете прохождение, сначала сделайте отдельную копию проекта. Не проходите курс в исходной папке, которую будете публиковать.

## Подготовка

1. Откройте эту папку в VS Code.
2. Найдите файл `CLAUDE.md`.
3. Найдите файл `course/README.md`.
4. Найдите файл `student-work/progress.md`.
5. Откройте шпаргалку `handouts/markdown-basics.md`.
6. Откройте диалог с ИИ-ассистентом в VS Code.

Obsidian понадобится во втором модуле. Если он еще не установлен, ассистент мягко проведет вас через установку и открытие vault.

## Стартовый промпт

Скопируйте текст ниже в ассистента:

```text
Привет! Я прохожу курс из этого репозитория: "От хаоса к системе: Obsidian для личного контекста".

Пожалуйста, будь моим наставником по курсу. Веди меня последовательно, внутри этого одного диалога.

Учитывай файлы:
- CLAUDE.md
- course/README.md
- handouts/markdown-basics.md
- student-work/progress.md

Я только начинаю вайбкодить, поэтому объясняй простыми словами, но не упрощай смысл. Мне важно понять теорию накопительного контекста, научиться вести Obsidian vault и выполнять задания в VS Code.

Когда просишь меня открыть или заполнить файл, давай кликабельную Markdown-ссылку на него. Если можешь открыть файл сам, открой его и скажи, какие поля мне заполнить.

Начни с вводного урока и скажи, какой файл открыть первым.
```

## Правила прохождения

- Не открывайте новый чат для каждого урока.
- Не пропускайте чекпоинты.
- Не храните важные выводы только в диалоге.
- После каждого модуля обновляйте `student-work/progress.md`.

## Если ассистент сбился

Скопируйте ему этот текст:

```text
Вернись к роли наставника из CLAUDE.md. Мы проходим курс последовательно в одном диалоге. Сначала проверь мой текущий прогресс в student-work/progress.md, затем продолжи с ближайшего незавершенного модуля.
```
