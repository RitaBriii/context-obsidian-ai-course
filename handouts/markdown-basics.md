# Шпаргалка. Markdown-минимум для курса

Markdown — это простой формат для текстовых файлов. Он помогает делать заголовки, списки, ссылки и короткие выделения без сложной верстки.

## Файлы Markdown

Markdown-файлы обычно заканчиваются на `.md`:

- `README.md`;
- `checkpoint.md`;
- `progress.md`;
- `context-map.md`.

Такие файлы можно открыть в Codex, Obsidian, GitHub или обычном текстовом редакторе.

## Заголовки

```md
# Заголовок первого уровня

## Заголовок второго уровня

### Заголовок третьего уровня
```

## Списки

Для списка используйте дефис, затем пробел:

```md
- Первый пункт
- Второй пункт
- Третий пункт
```

Важно: между дефисом и текстом должен быть пробел.

Правильно:

```md
- Моя заметка
```

Неправильно:

```md
-Моя заметка
```

## Нумерованные шаги

```md
1. Открыть файл
2. Заполнить раздел
3. Показать ассистенту
```

## Имена файлов и короткие команды

Чтобы выделить имя файла или команду, используйте обратные кавычки:

```md
Откройте `checkpoint.md`.
```

## Ссылки Obsidian

В Obsidian связи между заметками пишутся так:

```md
[[Название заметки]]
```

## Главное правило

Markdown не нужно писать идеально. Достаточно, чтобы файл был понятен вам, ассистенту и будущему вам через неделю.
