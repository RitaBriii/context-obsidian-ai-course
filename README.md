# Курс: От хаоса к системе: Obsidian для личного контекста

Это учебный проект для самостоятельного прохождения вместе с Codex. Ученик скачивает репозиторий с GitHub, открывает папку проекта в Codex и выполняет задания прямо в файлах.

Главная идея курса: контекст не нужно каждый раз собирать с нуля. Его можно выращивать как личный граф знаний: Obsidian vault, память команд, заметки по проектам, сохраненные источники, разборы ошибок, промпты, решения и правила работы. Такая система делает ИИ-ассистента точнее, быстрее и полезнее.

## Для кого

- Для новичков в вайбкодинге, которые уже умеют просить ИИ написать код или текст.
- Для тех, кто только начал вайбкодить и хочет быстрее понимать проекты, команды, ошибки и работу с ИИ.
- Для тех, кто теряет важные решения между сессиями.
- Для тех, кто хочет связать Obsidian, Markdown-файлы и Codex в единую рабочую систему.

## Быстрый старт для ученика

1. Скачайте этот проект с GitHub.
2. Распакуйте архив или клонируйте репозиторий.
3. Откройте папку проекта в Codex.
4. Откройте файл [START_HERE.md](START_HERE.md).
5. Скопируйте стартовый промпт из этого файла в ИИ-ассистента.
6. Дальше продолжайте в этой же задаче Codex.

По возможности не создавайте новую задачу для каждого урока: одна задача показывает, как контекст постепенно накапливается. Если задача прервалась, продолжите по файлу `student-work/progress.md` — важный контекст должен храниться не только в диалоге.

## Важно для автора курса и администратора

Не проходите курс в исходной папке, которую готовите к публикации. Сделайте отдельную копию проекта для тестового прохождения.

Если нужно сохранить личный прогресс рядом с курсом, используйте папку `my-work/`. Она добавлена в `.gitignore` и не должна попадать в GitHub-репозиторий.

Перед коммитом и пушем запустите:

```bash
bash scripts/check-course.sh
```

Проверка подтверждает, что ученические шаблоны остались эталонно чистыми, устаревшие названия не вернулись, а локальные Markdown-ссылки не сломаны.

## Как проходить

1. Откройте проект в Codex и начните одну задачу.
2. Попросите ассистента вести вас по курсу из этого репозитория.
3. Идите по урокам из [course/README.md](course/README.md).
4. Выполняйте задания в файлах из [exercises/](exercises/README.md).
5. После каждого модуля заполняйте `checkpoint.md`.
6. Ассистент проверяет чекпоинт и решает, можно ли идти дальше.

## Роль ИИ-ассистента

Курс рассчитан на прохождение вместе с ИИ-ассистентом. Ассистент должен:

- задавать уточняющие вопросы;
- помогать ученику формировать заметки;
- проверять чекпоинты;
- предлагать улучшения структуры vault;
- помогать превращать разовые находки в постоянную память.

Инструкции наставника лежат в [AGENTS.md](AGENTS.md). Codex читает их как проектные инструкции.

## Структура

- `START_HERE.md` — точка входа и первый промпт.
- `course/` — основные уроки курса.
- `exercises/` — практические задания тренажера.
- `student-work/` — рабочая тетрадь ученика.
- `handouts/` — скачиваемые конспекты после уроков.
- `portal/` — тексты для загрузки курса на учебный портал.
- `templates/obsidian-vault/` — стартовый шаблон Obsidian vault.
- `templates/assistant/` — промпты и роли для ИИ-наставника.

## Результат курса

К концу курса у ученика будет:

- рабочий Obsidian vault для ИИ-контекста;
- карта проектов, источников и решений;
- память команд и рабочих приемов;
- шаблон сессии с ИИ;
- привычка сохранять знания так, чтобы ассистент мог использовать их в следующих задачах.
