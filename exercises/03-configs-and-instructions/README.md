# Упражнение 3. Конфиг и инструкции для ассистента

Цель: понять, как проектные инструкции помогают ассистенту работать точнее и не заставляют вас каждый раз объяснять правила заново.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Откройте `assistant-config-template.md`.
2. Заполните разделы про цель проекта, роль ассистента и правила работы.
3. Если у вас пока нет своего проекта, заполните шаблон для прохождения этого курса.
4. Покажите файл ассистенту и попросите проверить, достаточно ли понятно ему, как вам помогать.
5. Заполните `checkpoint.md`.
6. Перенесите важный вывод в `student-work/session-log.md`.

## Критерий готовности

У вас есть первый файл проектных инструкций, который можно дать ассистенту перед работой.
