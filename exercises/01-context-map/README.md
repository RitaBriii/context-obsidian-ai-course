# Упражнение 1. Карта личного контекста

Цель: увидеть, какой контекст у вас уже есть, а какой каждый раз приходится объяснять ИИ заново.

## Перед заполнением

Откройте шпаргалку [../../handouts/markdown-basics.md](../../handouts/markdown-basics.md), если еще не уверены в Markdown.

Для списков используйте формат:

```md
- Один пункт
- Второй пункт
```

Между дефисом и текстом должен быть пробел.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Откройте `my-work/exercises/01-context-map/context-map.md`.
2. Заполните разделы `Проекты`, `Повторяющиеся задачи`, `Команды`, `Источники`, `Решения`.
3. Отметьте, что уже сохранено в файлах, а что живет только в памяти.
4. Заполните `my-work/exercises/01-context-map/checkpoint.md`.
5. Напишите «готово». Ассистент сам прочитает заполненные файлы и выделит три самые полезные зоны для накопления контекста.
6. Перенесите главный вывод в `my-work/student-work/session-log.md`.

## Критерий готовности

У вас есть список из 5-10 элементов контекста, которые стоит перенести в Obsidian vault.
