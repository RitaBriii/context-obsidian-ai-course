# Упражнение 5. Источник как часть графа

Цель: превратить статью, книгу или документацию в рабочее знание для ИИ-сессий.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Выберите один источник: книгу, статью, документацию, видео или полезный ответ ИИ.
2. Откройте `my-work/exercises/05-sources/source-template.md`.
3. Заполните главную идею своими словами.
4. Добавьте, где это применимо в ваших проектах или вайбкодинг-практике.
5. Перенесите заметку в `my-work/obsidian-vault/40-sources/`.
6. Заполните `my-work/exercises/05-sources/checkpoint.md`.
7. Напишите «готово». Ассистент сам прочитает заметку и предложит связи с уже созданными материалами.

## Критерий готовности

Источник связан хотя бы с одним проектом, решением или будущим действием.
