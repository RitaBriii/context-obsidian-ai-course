# Упражнение 2. Стартовый Obsidian vault

Цель: создать структуру vault, в которой ИИ сможет находить проекты, решения, команды и источники.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Если Obsidian еще не установлен, попросите ассистента провести вас через установку с официального сайта `https://obsidian.md/download`.
2. Скопируйте содержимое `templates/obsidian-vault` в отдельную папку вашего vault или изучите шаблон прямо в репозитории.
3. Откройте Obsidian.
4. Выберите открытие папки как vault.
5. Укажите папку со стартовым vault.
6. Создайте заметку проекта в `10-projects`.
7. Создайте хотя бы две ссылки между заметками.
8. Заполните `checkpoint.md`.
9. Обновите `student-work/vault-plan.md`.

## Критерий готовности

Есть стартовая структура vault и хотя бы одна карта проекта, связанная с решением, командой или источником.
