# Упражнение 2. Стартовый Obsidian vault

Цель: создать структуру vault, в которой ИИ сможет находить проекты, решения, команды и источники, и настроить обязательную локальную историю изменений через Git и Obsidian Git.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Если Obsidian ещё не установлен, сообщите об этом в текущем диалоге. Наставник проведёт вас через установку с официального сайта `https://obsidian.md/download`, по одному шагу за раз.
2. Используйте личную копию vault, созданную в `my-work/obsidian-vault/`.
3. Откройте Obsidian.
4. Выберите открытие папки как vault.
5. Укажите папку `my-work/obsidian-vault/`.
6. Создайте заметку проекта в `10-projects`.
7. Создайте хотя бы две ссылки между заметками.
8. Пройдите обязательную инструкцию [Локальный Git и Obsidian Git](../../course/02-git-sync.md).
9. Codex инициализирует Git в `my-work/obsidian-vault/` и создаст первый локальный commit после проверки рабочей папки.
10. Установите Obsidian Git и включите автоматический локальный backup/commit каждые пять минут.
11. Измените заметку проекта и напишите «готово». Codex проверит новый commit через `git log`.
12. Если у вас уже есть доступ и подходящий репозиторий на `gitlab.agimagroup.ru`, дополнительно подключите remote и проверьте commit-and-sync. Не создавайте заявку на доступ специально для курса.
13. Заполните `my-work/exercises/02-obsidian-vault/checkpoint.md`.
14. Обновите `my-work/student-work/vault-plan.md`.

## Критерий готовности

Есть стартовая структура vault, хотя бы одна карта проекта со связями и подтверждённый локальный commit, созданный через Obsidian Git. GitLab не требуется для завершения модуля, если доступа к подходящему репозиторию ещё нет.
