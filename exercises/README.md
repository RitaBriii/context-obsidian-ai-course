# Тренажер

Каждое упражнение устроено одинаково:

- `README.md` — задание;
- `checkpoint.md` — чистая форма для результата;
- дополнительные файлы — чистые рабочие шаблоны.

При первом запуске Codex выполняет `bash scripts/start-course.sh`. Скрипт копирует формы в `my-work/exercises/`. Ученик заполняет только эти личные копии. После выполнения он пишет «готово», а Codex сам читает соответствующий `checkpoint.md` внутри `my-work/` и дает обратную связь.

## Важно

По возможности не создавайте новую задачу для каждого упражнения. Если задача прервалась, продолжите по `my-work/student-work/progress.md`: ценность тренажера в том, что устойчивый контекст остается в файлах, а не только в истории диалога.
