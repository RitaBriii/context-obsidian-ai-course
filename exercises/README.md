# Тренажер

Каждое упражнение устроено одинаково:

- `README.md` — задание;
- `checkpoint.md` — форма для результата;
- дополнительные файлы — рабочие материалы.

Ученик выполняет упражнение в VS Code в том же диалоге с ИИ-ассистентом, в котором проходит курс. После выполнения он показывает `checkpoint.md` ассистенту и получает обратную связь.

## Важно

Не создавайте новый чат для нового упражнения. Вся ценность тренажера в том, что ассистент постепенно узнает вашу ситуацию, проекты, ошибки, команды и стиль работы.
