# Тренажер

Каждое упражнение устроено одинаково:

- `README.md` — задание;
- `checkpoint.md` — форма для результата;
- дополнительные файлы — рабочие материалы.

Ученик выполняет упражнение в файлах проекта в текущей задаче Codex. После выполнения он пишет «готово», а Codex сам читает соответствующий `checkpoint.md` и дает обратную связь.

## Важно

По возможности не создавайте новую задачу для каждого упражнения. Если задача прервалась, продолжите по `student-work/progress.md`: ценность тренажера в том, что устойчивый контекст остается в файлах, а не только в истории диалога.
