# Упражнение 4. Память команд

Цель: перестать заново спрашивать ИИ о командах, которые уже выяснены.

## Шаги

0. Оставайтесь в текущем диалоге с ассистентом.
1. Откройте `my-work/exercises/04-command-memory/command-template.md`.
2. Заполните его для одной реальной команды, которую вы используете или спрашивали у ИИ.
3. Если реальной команды пока нет, сообщите об этом в текущем диалоге. Ассистент сам изучит проект и предложит безопасный пример.
4. Добавьте частые ошибки или условия запуска.
5. Перенесите заметку в `my-work/obsidian-vault/30-commands/`.
6. Заполните `my-work/exercises/04-command-memory/checkpoint.md`.
7. Добавьте команду в `my-work/student-work/session-log.md`.

## Критерий готовности

У вас есть одна команда, которую ассистент сможет использовать в будущих сессиях без повторного объяснения.
