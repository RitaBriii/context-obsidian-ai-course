# Чистые шаблоны рабочей тетради

Эта публичная папка хранит эталонно чистые шаблоны. Не заполняйте их во время прохождения курса.

Команда `bash scripts/start-course.sh` копирует рабочие файлы в `my-work/student-work/`. Заполняйте только личные копии внутри `my-work/`: эта папка исключена из Git и не перезаписывается при повторном запуске скрипта.

## Файлы

- `progress.md` — чистый шаблон прогресса по модулям.
- `session-log.md` — чистый шаблон журнала сессии.
- `vault-plan.md` — чистый шаблон плана Obsidian vault.
