# Рабочая тетрадь ученика

Эта папка хранит личный прогресс прохождения курса.

Заполняйте файлы здесь во время курса. Это не идеальный конспект, а рабочая память: она помогает ассистенту понимать, где вы находитесь и что уже сделали.

## Файлы

- `progress.md` — текущий прогресс по модулям.
- `session-log.md` — заметки по одному диалогу с ассистентом.
- `vault-plan.md` — план вашего будущего Obsidian vault.
