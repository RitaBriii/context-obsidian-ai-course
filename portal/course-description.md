# Описание курса для учебного портала

## Название

От хаоса к системе: Obsidian для личного контекста

## Короткое описание

Курс учит новичков в вайбкодинге не начинать каждую задачу с ИИ заново, а постепенно накапливать рабочий контекст: заметки, решения, команды, источники, промпты и связи между ними. Ученик скачивает проект с GitHub, открывает его в Codex и выполняет задания прямо в файлах.

## Полное описание

Многие начинающие вайбкодеры быстро учатся просить ИИ написать код, объяснить ошибку или предложить решение. Но без системы контекста они постоянно возвращаются в одну и ту же точку: заново объясняют проект, теряют удачные команды, забывают причины решений и не сохраняют полезные ответы ассистента.

Этот курс помогает построить личную систему накопительного контекста. Ученик работает с Codex и постепенно переносит важные знания из диалога в файлы и Obsidian vault. В результате чат перестает быть единственным местом памяти, а превращается в рабочий процесс, который питает личный граф знаний.

В курсе есть теория, практические задания, чекпоинты, шаблон Obsidian vault, рабочая тетрадь ученика и конспекты к каждому уроку.

ИИ-ассистент ведет ученика пошагово: дает ссылки на нужные файлы, просит заполнить конкретные разделы, проверяет чекпоинты и помогает переносить важные выводы в устойчивую память.

## Для кого курс

- Для тех, кто только начал вайбкодить.
- Для тех, кто уже пользуется ИИ-ассистентом, но каждый раз собирает контекст заново.
- Для тех, кто хочет навести порядок в заметках, командах, источниках и решениях.
- Для тех, кто хочет связать Codex, Obsidian и Markdown-файлы в единую рабочую систему.

Для обязательной практики понадобится Git. Корпоративный GitLab подключается только у учеников, которым уже доступен подходящий репозиторий; запрашивать доступ ради курса не требуется.

## Что ученик научится делать

- Проходить ИИ-сессию так, чтобы результат не терялся после закрытия чата.
- Отличать разовый контекст от накопительного.
- Заполнять простые Markdown-файлы курса без страха перед форматом.
- Создавать Obsidian vault для проектов, решений, команд и источников.
- Вести локальную историю vault через Git и Obsidian Git и при наличии готового доступа подключать корпоративный remote.
- Понимать, что такое конфиги и проектные инструкции.
- Вести память команд и рабочих ошибок.
- Сохранять книги, статьи, документацию и ответы ИИ как полезные источники.
- Готовить brief для ИИ-ассистента и завершать сессию обновлением контекста.

## Формат прохождения

Ученик скачивает репозиторий с GitHub, открывает его в Codex и начинает с файла `START_HERE.md`. По возможности курс проходится в одной задаче Codex, а сохраненные файлы позволяют продолжить после любого перезапуска. После каждого модуля ученик выполняет практическое задание и заполняет чекпоинт.

## Итоговый результат

К концу курса у ученика будет стартовый Obsidian vault с локальной Git-историей, карта личного контекста, память команд, заметка по источнику, шаблон полной ИИ-сессии и привычка переносить полезные знания из чата в устойчивую систему. При уже имеющемся доступе vault также может синхронизироваться с корпоративным GitLab.
