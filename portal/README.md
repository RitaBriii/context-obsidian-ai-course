# Материалы для учебного портала

Эта папка содержит тексты, которые можно использовать при загрузке курса на обучающую платформу:

- [course-description.md](course-description.md) — описание курса для карточки или лендинга.
- [student-instructions.md](student-instructions.md) — инструкция для ученика перед стартом.
- [module-descriptions.md](module-descriptions.md) — описания уроков и практических заданий.
- [completion-criteria.md](completion-criteria.md) — критерии прохождения и проверки результата.
