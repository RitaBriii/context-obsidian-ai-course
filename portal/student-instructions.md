# Инструкция для ученика

## Перед началом

Вам понадобится:

- VS Code;
- ИИ-ассистент внутри VS Code или рядом с ним;
- Obsidian;
- скачанный проект курса с GitHub.

## Как начать пошагово

### Шаг 1. Скачайте учебный проект

Есть два варианта.

Вариант 1 — через Git:

```bash
git clone https://github.com/RitaBriii/context-obsidian-ai-course.git
```

После этого откройте папку:

```bash
cd context-obsidian-ai-course
```

Вариант 2 — через браузер:

1. Откройте страницу курса: `https://github.com/RitaBriii/context-obsidian-ai-course`.
2. Нажмите зеленую кнопку `Code`.
3. Выберите `Download ZIP`.
4. Распакуйте архив на компьютере.

### Шаг 2. Откройте проект в VS Code

1. Откройте VS Code.
2. Выберите `File` → `Open Folder`.
3. Найдите папку `context-obsidian-ai-course`.
4. Откройте ее.

Важно: открывайте именно папку проекта целиком, а не отдельный файл.

### Шаг 3. Откройте стартовый файл

В VS Code откройте файл:

`START_HERE.md`

В нем находится стартовый промпт для ИИ-ассистента и правила прохождения курса.

### Шаг 4. Откройте ИИ-ассистента

Откройте ИИ-ассистента, с которым будете проходить курс. Это может быть ассистент внутри VS Code или отдельное окно рядом с VS Code.

Важно: весь курс нужно проходить в одном диалоге. Не начинайте новый чат для каждого модуля.

### Шаг 5. Отправьте ассистенту стартовый промпт

Скопируйте и отправьте ассистенту этот текст:

```text
Привет! Я прохожу курс из этого репозитория: "От хаоса к системе: Obsidian для личного контекста".

Пожалуйста, будь моим наставником по курсу. Веди меня последовательно, внутри этого одного диалога.

Учитывай файлы:
- CLAUDE.md
- course/README.md
- handouts/markdown-basics.md
- student-work/progress.md

Я только начинаю вайбкодить, поэтому объясняй простыми словами, но не упрощай смысл. Мне важно понять теорию накопительного контекста, научиться вести Obsidian vault и выполнять задания в VS Code.

Когда просишь меня открыть или заполнить файл, давай кликабельную Markdown-ссылку на него. Если можешь открыть файл сам, открой его и скажи, какие поля мне заполнить.

Начни с вводного урока и скажи, какой файл открыть первым.
```

### Шаг 6. Следуйте указаниям ассистента

Ассистент должен:

- объяснять теорию простыми словами;
- давать ссылку на файл, который нужно открыть;
- просить заполнить конкретные разделы;
- проверять ваши чекпоинты;
- помогать переносить важные выводы в Obsidian, заметки и память команд.

### Шаг 7. После каждого модуля обновляйте прогресс

После каждого модуля обновляйте файл:

`student-work/progress.md`

Отмечайте пройденный модуль и записывайте последний завершенный шаг.

## Главное правило

Не начинайте новый чат для каждого урока. Один диалог нужен специально: вы будете видеть, как ассистент постепенно получает больше контекста, а вы учитесь переносить важные выводы из чата в файлы и Obsidian.

## Как устроен модуль

Каждый модуль состоит из:

- теоретического урока в папке `course`;
- практического задания в папке `exercises`;
- чекпоинта `checkpoint.md`;
- обновления рабочей тетради в `student-work`;
- конспекта в папке `handouts`.

Перед первым упражнением ученику стоит открыть `handouts/markdown-basics.md`. Там объясняется, как заполнять `.md`-файлы: заголовки, списки, пробел после дефиса, имена файлов и ссылки Obsidian.

Во втором модуле вам понадобится Obsidian. Если он еще не установлен, ассистент объяснит, как установить его с официального сайта `https://obsidian.md/download` и открыть папку как vault.

## Как сдавать результат

После каждого практического задания покажите ассистенту заполненный `checkpoint.md`. Ассистент должен проверить, можно ли идти дальше, и подсказать, какие заметки, команды, решения или источники стоит сохранить.

Ассистент должен давать кликабельные ссылки на файлы, которые нужно открыть или заполнить. Если ссылка не открывается в вашей среде, используйте путь рядом со ссылкой.

## Что делать после урока

После прохождения урока откройте соответствующий конспект в папке `handouts`. Его можно сохранить отдельно, распечатать или использовать как шпаргалку для будущих ИИ-сессий.
