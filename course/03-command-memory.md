# 3. Память команд и рабочих решений

Команды — это один из самых недооцененных видов контекста. Ученик может десять раз просить ИИ вспомнить, как запускать тесты, миграции, сборку или проверку форматирования. Но лучше сохранить это один раз.

## Что сохранять

В память команд стоит заносить:

- команды запуска проекта;
- команды тестов и линтинга;
- команды диагностики;
- команды сборки;
- частые ошибки и способы исправления;
- условия, при которых команда работает.

## Формат записи команды

Используйте простой шаблон:

````md
# Команда: npm test

## Когда использовать

Перед отправкой изменений, чтобы проверить тесты.

## Команда

```bash
npm test
```

## Что означает успешный результат

Все тесты проходят без ошибок.

## Частые проблемы

- Не установлены зависимости: выполнить `npm install`.
- Тест требует переменные окружения: проверить `.env.example`.
````

## Почему это усиливает ИИ

Когда ассистент видит память команд, он меньше гадает. Он может:

- предложить правильную проверку;
- не запускать неподходящую команду;
- объяснить ошибку в контексте проекта;
- обновить память, если команда изменилась.
