# Программа курса

Курс состоит из вводного урока и пяти модулей. Каждый модуль дает теорию, показывает практический принцип и закрепляется упражнением в VS Code.

## Модули

0. [Как устроен этот курс](00-how-this-course-works.md)
1. [Контекст не промпт, а система](01-context-system.md)
2. [Obsidian vault как граф знаний](02-obsidian-vault.md)
3. [Конфиги и проектные инструкции](03-configs-and-instructions.md)
4. [Память команд и рабочих решений](03-command-memory.md)
5. [Источники, книги и внешние знания](04-sources-and-books.md)
6. [Полная сессия с ИИ-ассистентом](05-full-ai-session.md)

## Как работать с модулем

1. Прочитайте урок.
2. Откройте соответствующее упражнение.
3. Выполните задания в файлах упражнения.
4. Заполните `checkpoint.md`.
5. Попросите ИИ-ассистента проверить результат.
6. Обновите [student-work/progress.md](../student-work/progress.md).
7. Откройте конспект урока в [handouts](../handouts/README.md).

## Главное правило

Весь курс проходится в одном диалоге с ассистентом. Это не техническая случайность, а часть обучения: ученик на практике видит, как контекст сначала собирается, затем уточняется, затем начинает помогать.

## Минимальный ритм

Один модуль можно пройти за 30-60 минут. Лучше не спешить: цель курса не прочитать материалы, а создать систему, которой ученик начнет пользоваться в реальной работе.
