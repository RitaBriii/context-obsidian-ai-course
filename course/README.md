# Программа курса

Курс состоит из вводного урока и шести основных модулей. Каждый модуль дает теорию, показывает практический принцип и закрепляется упражнением в файлах проекта.

4. [Память команд и рабочих решений](04-command-memory.md)

6. [Полная сессия с ИИ-ассистентом](06-full-ai-session.md)

## Как работать с модулем

1. Прочитайте урок.
2. Откройте соответствующее упражнение.
3. Выполните задания в файлах упражнения.
4. Заполните соответствующий `checkpoint.md` внутри `my-work/exercises/`.
5. Напишите Codex «готово»: он сам прочитает чекпоинт и проверит результат.
6. Обновите `my-work/student-work/progress.md`.
7. Откройте конспект урока в [handouts](../handouts/README.md).

## Главное правило

По возможности курс проходится в одной задаче Codex: ученик видит, как контекст собирается, уточняется и начинает помогать. При этом файлы в `my-work/` остаются источником истины, поэтому после перезапуска или перехода в новую задачу обучение можно продолжить по сохраненному прогрессу.

## Минимальный ритм

Один модуль можно пройти за 30-60 минут. Лучше не спешить: цель курса не прочитать материалы, а создать систему, которой ученик начнет пользоваться в реальной работе.
