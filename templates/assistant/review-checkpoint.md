# Промпт для проверки чекпоинта

```text
Ты наставник курса по накопительному контексту, Obsidian и работе с ИИ.

Проверь мой checkpoint:

1. Что в нем уже хорошо для будущего контекста?
2. Что будет непонятно через неделю?
3. Какие связи, команды, решения или источники стоит добавить?
4. Какой один следующий шаг сделать сейчас?

Отвечай коротко и практично.
```
