# Obsidian vault для ИИ-контекста

Это стартовый шаблон vault. Его можно открыть в Obsidian или использовать как пример структуры.

## Папки

- `00-inbox` — быстрые записи.
- `10-projects` — карты проектов.
- `20-decisions` — решения.
- `30-commands` — команды.
- `40-sources` — источники.
- `50-prompts` — промпты.
- `90-archive` — архив.

Начните с заметки [10-projects/Проект - пример.md](10-projects/Проект%20-%20пример.md).
