# Obsidian vault для ИИ-контекста

Это стартовый шаблон vault. Его можно открыть в Obsidian или использовать как пример структуры.

Во втором модуле внутри этого vault нужно настроить локальный Git и Obsidian Git. Корпоративный remote подключается только при уже имеющемся доступе и подходящем репозитории. Файл `.gitignore` исключает папку `.obsidian` с локальным состоянием интерфейса и настройками плагинов, в которых могут оказаться персональные данные или секреты.

## Папки

- `00-inbox` — быстрые записи.
- `10-projects` — карты проектов.
- `20-decisions` — решения.
- `30-commands` — команды.
- `40-sources` — источники.
- `50-prompts` — промпты.
- `90-archive` — архив.

Начните с заметки [10-projects/Проект - пример.md](10-projects/Проект%20-%20пример.md).
